# Accessibility Checklist for UI Review

## Quick Checks

### Visual
- [ ] Color contrast 4.5:1 minimum
- [ ] Text resizable to 200%
- [ ] Focus indicator visible
- [ ] Don't rely on color alone

### Keyboard
- [ ] All actions keyboard accessible
- [ ] Focus order logical
- [ ] No keyboard traps
- [ ] Skip navigation provided

### Semantic HTML
- [ ] Use proper heading hierarchy
- [ ] Use lists for list items
- [ ] Use tables for tabular data
- [ ] Use landmarks for regions

### Forms
- [ ] Labels associated with inputs
- [ ] Error messages clear
- [ ] Required fields indicated
- [ ] Group related fields

### Images
- [ ] Alt text provided
- [ ] Decorative images hidden
- [ ] Complex images described

### Motion
- [ ] Animations can be disabled
- [ ] No flashing content
- [ ] Auto-playing content pausable

## Common Issues

| Issue | Fix |
|-------|-----|
| Missing alt text | Add descriptive alt text |
| Low contrast | Increase color contrast |
| No focus indicator | Add visible focus styles |
| Missing labels | Associate labels with inputs |
| Incorrect heading order | Maintain logical hierarchy |
