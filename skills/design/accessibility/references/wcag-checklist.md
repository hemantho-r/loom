# Accessibility Checklist

## WCAG 2.1 Level AA Requirements

### Perceivable

1.1.1 Non-text Content
- All images have alt text
- Decorative images use empty alt
- Complex images have long descriptions

1.2.1 Audio-only and Video-only
- Audio has text transcript
- Video has audio description or text alternative

1.2.2 Captions
- Pre-recorded video has captions
- Live video has captions

1.3.1 Info and Relationships
- Semantic HTML used
- Headings hierarchy correct
- Lists properly structured
- Tables have headers

1.3.2 Meaningful Sequence
- Reading order logical
- CSS doesn't break reading order

1.3.3 Sensory Characteristics
- Instructions don't rely on shape/color alone

1.4.1 Use of Color
- Color not sole means of conveying info

1.4.2 Audio Control
- Audio can be paused/stoppped

1.4.3 Contrast (Minimum)
- Text contrast 4.5:1 minimum
- Large text contrast 3:1 minimum

1.4.4 Resize Text
- Text resizable to 200%
- No loss of content

1.4.5 Images of Text
- No images of text (with exceptions)

### Operable

2.1.1 Keyboard
- All functionality keyboard accessible

2.1.2 No Keyboard Trap
- Focus can move away from components

2.1.4 Character Key Shortcuts
- Shortcuts can be remapped

2.2.1 Timing Adjustable
- Time limits can be extended

2.2.2 Pause, Stop, Hide
- Moving content can be paused

2.3.1 Three Flashes
- No content flashes more than 3 times

2.4.1 Bypass Blocks
- Skip navigation provided

2.4.2 Page Titled
- Pages have descriptive titles

2.4.3 Focus Order
- Focus order logical

2.4.4 Link Purpose
- Link purpose clear from text

2.4.5 Multiple Ways
- Multiple ways to find pages

2.4.6 Headings and Labels
- Headings descriptive
- Labels descriptive

2.4.7 Focus Visible
- Focus indicator visible

### Understandable

3.1.1 Language of Page
- Page language declared

3.1.2 Language of Parts
- Part language marked

3.2.1 On Focus
- No unexpected context changes

3.2.2 On Input
- No unexpected context changes

3.3.1 Error Identification
- Errors clearly identified

3.3.2 Labels or Instructions
- Labels provided

3.3.3 Error Suggestion
- Error suggestions provided

3.3.4 Error Prevention
- Submissions can be reversed

### Robust

4.1.1 Parsing
- Valid HTML

4.1.2 Name, Role, Value
- Custom components have accessible names
- Roles correctly applied
- States and properties exposed
