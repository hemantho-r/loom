# Theme Catalog

Pick a genre first, then a theme inside it — never the default. Record the
choice and rotate across runs (see `macrostructures.md` for layout rotation).

## Genres

- **Editorial** — magazine-like, big serif headlines, generous whitespace.
- **Modern minimal** — restrained palette, single accent, lots of air.
- **Bold & vibrant** — saturated color, large type, high energy.
- **Quiet professional** — muted neutrals, small accents, dense information.
- **Playful** — rounded shapes, warm colors, informal type.

## Rotation rule

Keep a rotation log (starter: `templates/rotation-log.md` — copy it into
your project or PR description): the last two genre/theme pairs used. The
next run must pick a different genre unless the brand mandates one.
"Default" (no explicit choice) fails the `theme-rotation` gate.
