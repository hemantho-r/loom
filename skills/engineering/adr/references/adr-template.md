# ADR Template

## Standard Template

```markdown
# ADR [Number]: [Title]

**Date:** [YYYY-MM-DD]

**Status:** [Proposed | Accepted | Deprecated | Superseded]

**Deciders:** [List of people involved]

## Context

[Describe the situation and problem]

### Current State
[How things work now]

### Requirements
[What we need to achieve]

### Constraints
[Limits and restrictions]

## Decision

[State the decision clearly]

### Chosen Approach
[What we're doing]

### Implementation
[How we'll implement it]

## Alternatives Considered

### Option 1: [Name]
**Description:** [What it is]
**Pros:** [Benefits]
**Cons:** [Drawbacks]
**Why rejected:** [Reason]

### Option 2: [Name]
**Description:** [What it is]
**Pros:** [Benefits]
**Cons:** [Drawbacks]
**Why rejected:** [Reason]

## Consequences

### Positive
- [Benefit 1]
- [Benefit 2]

### Negative
- [Trade-off 1]
- [Trade-off 2]

### Risks
- [Risk 1]
- [Risk 2]

### Mitigations
- [How to address Risk 1]
- [How to address Risk 2]

## References

- [Link to related ADR]
- [Link to documentation]
```

## Quick Template

```markdown
# ADR: [Title]

**Status:** Accepted

**Context:** [Problem]

**Decision:** [What we're doing]

**Alternatives:** [What else was considered]

**Consequences:** [Trade-offs]
```
