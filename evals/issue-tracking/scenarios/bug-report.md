# Issue Tracking Eval: Bug Report

## Scenario

File an issue for the login redirect bug: after password reset, users land
on a 404 instead of the dashboard. Reproducible in staging, not yet in prod.

## Requirements

- Description states what and why with repro steps
- Acceptance criteria are falsifiable
- Priority, type, and status labels are all set

## Expected Behavior

1. Title names the symptom and scope
2. Repro steps + expected vs. actual behavior
3. Criteria like "reset → login lands on dashboard, never 404"
4. Labels: priority high, type bug, status todo

## Quality Gates

- **has-description**: Issue has clear description
- **has-acceptance-criteria**: Issue has acceptance criteria
- **has-labels**: Issue has appropriate labels
