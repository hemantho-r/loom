# Handoff Eval: Session Transfer

## Scenario

Hand off mid-feature work: OAuth login is half-built (Google wired, GitHub
pending), blocked on the client secret from the platform team, with next
steps known.

## Requirements

- Record current state honestly (what works, what doesn't)
- Name the blocker and what unblocks it
- Sequence next steps so a stranger starts without questions

## Expected Behavior

1. State: Google flow works end to end; GitHub not started
2. Blocked: client secret, owner (platform team), expected Thursday
3. Next steps ordered (secret → GitHub wiring → account-linking decision)
4. References resolve (files, issue, docs)

## Quality Gates

- **completeness**: Handoff includes all necessary context
- **clarity**: Handoff is clear and unambiguous
- **actionable**: Handoff includes next steps
