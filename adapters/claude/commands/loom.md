# Loom Commands

## Install a skill
```bash
loom install <package>
```

## List installed skills
```bash
loom list
```

## Compose skills
```bash
loom compose <skills...>
```

## Test skills
```bash
loom test [skill]
```

## Validate skills
```bash
loom validate [skill]
```
